## 1. Regras de preenchimento

| # | Regra |
|---|-------|
| 1 | Preencher no mesmo dia da entrevista (memória decai em horas) |
| 2 | Nunca nomear a empresa: usar `Construtora A`…`Construtora J` |
| 3 | Nome do entrevistado só no campo `contato_interno`, que **não** vai para material externo |
| 4 | Registrar **citação literal** entre aspas — não parafrasear |
| 5 | Registrar **objeções** mesmo que desconfortáveis, com a frase exata |
| 6 | Não corrigir a fala do entrevistado nem "traduzir" para o nosso vocabulário |
| 7 | Se não perguntou, deixar `N/R` (não respondido) — nunca deduzir |
| 8 | Se a resposta foi vaga, registrar como vaga (não completar com suposição) |
| 9 | Consentimento registrado antes de qualquer anotação identificável |
| 10 | Campo `surpresa`: o que contrariou a expectativa — o dado mais valioso da ficha |

## 3. Blocos de conteúdo (iguais para todos)

| Bloco | O que capturar | Campo |
|-------|----------------|-------|
| B0 | Contexto e papel | `b0_contexto` (texto) |

| B6 | Disposição a pagar | `software_pago_hoje` + `valor_software_rs` + `quem_assina` + `orcamento_existe` + `ancoragem_rs` |
